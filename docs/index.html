    安装插件

    添加市场源需要支持「插件市场」的 LovelyCarve 版本。

    从插件市场安装

    在 LovelyCarve 打开「设置 → 插件市场」并添加下方地址。选择插件并确认安装。

    https://lovelyteams.github.io/LovelyCarve-Plugin-Site/index.json

    手动安装插件包

    下载适合你操作系统的 .lcpkg。在「设置 → 插件」选择「安装插件包」，检视后确认安装。

    如果当前版本已内置该插件，可直接使用内置版本。
